# Лендинг Игоря Северова

Страница Next.js App Router: `/severov`. Изолированные CSS Modules, без новых зависимостей и iframe. Глобальный layout сохранён.

## Доработка

- Основной контакт — предоставленный профиль https://tenchat.ru/1858784. Неподтверждённый личный Telegram убран.
- Убраны неподтверждённые условия: 30 минут консультации, аудит за 10–15 дней, гарантированная выдача шаблона.
- Уточнены услуги ISO: подготовка, а не выдача сертификата.
- Добавлены 17 лет опыта и расширение в 3 раза — по материалам заказчика, без дополнительных выдуманных показателей.
- Опыт Nissan отделён от результата внешнего аудита ISO; утверждение о снижении брака на Nissan исключено как неподтверждённое.
- FAQ: исправлена опечатка в слове «простои».
