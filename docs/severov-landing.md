## Перед публикацией

- Согласовать тексты кейсов, условия бесплатной консультации и формат совместного аудита с экспертами.
- Добавить согласованный портрет в public/severov.webp и заменить монограмму в странице на next/image. В этой версии портрет не загружен: не выдавать монограмму за фотографию.
- Добавить /severov в навигацию и sitemap при согласовании размещения в структуре сайта.
- Выполнить npm ci и npm run build; проверить адаптивность и переходы. Сборка в рамках передачи через GitHub не запускалась.

Страница использует прямые переходы во внешние сервисы, серверной формы нет. Конкретные неподтверждённые проценты эффективности и отзывы не публикуются. Добавление страницы в ветку само по себе не означает публикацию на домене.
